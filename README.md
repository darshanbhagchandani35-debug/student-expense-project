# 🎓 Student Expense Tracker by D.H.Bhagchandani

A simple, lightweight C application designed to help students track and manage their daily expenses through an interactive terminal interface.

---

## ✨ Features

- **Add Expense**: Record new expenses quickly.
- **View Expenses**: Display a history of recorded expenses.
- **Calculate Total**: Sum up total expenditure automatically.
- **User-Friendly CLI**: Simple menu-driven navigation.

---

## 🛠️ Built With

- **Language**: C
- **IDE**: VS Code / Any standard C Compiler (GCC, Clang)

---
